# Summa 财务报告

在「报表」选择币种、期间和筛选条件，点击「导出财务报告」，选择 JSON、CSV、XLSX 或
Markdown。系统文件选择器用于保存。报告使用点击导出时的报表快照。日期范围包含
起止日，按设备本地日期划分，文件同时记录 UTC 起点和不含边界的 UTC 终点。

## 内容与口径

- 财务摘要包含收入、总消费、本人及外部承担、家庭资金转入、现金流和借还本金。
  分表列出收支分类、各账户现金变动和支出趋势。日、周、月、自定义区间按日汇总支出，
  自然年按月汇总。
- 资产负债取所选原币与账户范围内的启用账户，按期间边界重算期初、期末和变动额。
  受托资金可单列账户余额，净资产沿用现行口径。按分类、资金来源、支付渠道或交易对方
  筛选时，报告保留对应的收支和现金流，省略整户余额。
- 可选的匹配流水沿用报表筛选和已入账状态。每笔保留原币金额、实际结算金额与筛选后的
  统计贡献。拆分交易的贡献随当前账户、分类和资金来源筛选而变。跨币种划转按各侧实际
  入账金额汇总。消费、退款、冲销和现金流的口径见 [财务指标口径](FINANCIAL_METRICS.md)。
- 默认导出汇总。可分别打开「包含匹配流水」和「包含备注、支付渠道和交易对方」。
  关闭敏感字段时，已应用的原单筛选在范围中标记为 `redacted`。账户名和分类名
  会随报告导出。

## 文件格式

| 格式 | 结构与金额 |
| --- | --- |
| JSON | `format` 为 `summa_financial_report`，`report_version` 为 1。时间、币种、金额单位及筛选在 `scope`。摘要和分类等各自为数组。以 `_minor` 结尾的金额用十进制整数字符串保存。 |
| CSV | 带 UTF-8 BOM 的单个表格，按 `section` 区分摘要、范围及明细。金额以最小货币单位输出。用表格软件导入超长精确金额时，可将该列按文本读取。 |
| XLSX | 按报告分区生成工作表，冻结表头。可精确保存的金额为数字；超过 15 位的金额以文本保存。Excel 单元格长度以外的文本用省略号截断。 |
| Markdown | 用分区表格显示当期结果，金额按各行对应的币种及小数位格式化。 |

「导出账单」继续提供原有流水导出。「设置 → 数据与备份」提供完整 JSON 备份及恢复。
