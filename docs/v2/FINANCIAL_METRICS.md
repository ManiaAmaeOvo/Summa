# Summa 财务指标口径

## 首页

| 指标 | 统计口径 |
| --- | --- |
| 折算净资产 | 截至今日的启用账户余额。本人现金、储蓄、预付资产及应收本金计入资产，信用负债及应付他人本金计入负债。受托资金、家庭直接承担和外部授权额度不纳入。按当前估值设置折算为基准币种。缺少汇率时列出币种。 |
| 可用资金 | 所选币种截至今日的本人现金、银行、钱包及储蓄余额，逐账户扣除储蓄目标已预留金额，再将各账户可用金额相加。单一账户可用额最低为零。余额与预留缺口可在储蓄目标页核对。 |
| 本月消费 | 按所选币种汇总本地自然月起至今日的总消费和本人承担额。采用报表的消费口径。 |
| 预算余量 | 每项生效预算分别显示本期上限加上结转、扣除截至今日的使用额。多个预算可覆盖相同的交易。外部额度在预算与外部额度页面独立查看。 |
| 近期财务义务 | 现金流预测中今日起七天内尚待支付的周期支出、订阅和债务期款，含仍待支付的逾期项。未来日期已入账流水和预计回款可在预测明细查看。 |
| 待对账事项 | 启用账户最新一条未作废检查点如有差额，则显示实测余额减该时点账面余额。点选可进入对应账户对账。 |

## 收支和现金流

- 已入账流水按发生时间归入本地自然日、周、月或年。自定义区间包含起止日。
  待入账记录可在账单页复核。报表、历史分析和对应流水下钻使用已入账记录。
- 总消费扣除退款和冲销。代付垫付本金、借还本金和本人账户之间的转账属于资金移动。
  手续费和利息按归属币种及分类计入支出。本人承担额包括由他人先垫付且仍由本人
  承担的消费。家庭直接承担及受托资金代付分开呈现。
- 个人现金流按本人现金、银行、钱包和储蓄的实际分录计算，包含本金借入、偿还、
  借出和收回。全局汇总抵消本人现金账户间划转；指定账户时展示该账户实际收付。
  余额校准计入账户余额。家庭现金支持计入个人现金流入，同时在资金归属中单列。
- 账户、分类和资金来源组合筛选沿用报表分录分配。单笔交易下钻保留原交易和结算
  金额。支付渠道和交易对方按当前有效导入行筛选，组合时要求同一原单行同时匹配。
- 跨币种结算按两侧账户实际金额和币种读取历史分录。估值设置变动影响首页折算结果。
  历史分析每次选择一个原币，汇率记录不参与历史余额或收支计算。

## 历史分析

- 按月查看最近六期，按年查看最近三期。每期展示期末净资产、收入、总消费、
  本人承担额和个人净现金流，并列出相较上一期的差额。当前未结束的期间截至今日。
- 期末净资产由账户期初余额和截止日期前已入账的账户分录重算，包含余额调整。
  有早于账户创建日的历史交易时，以最早分录日期作为账本起点。归档账户按保留的归档
  时间参与较早期间。重新启用过的账户以现存启用状态重算。
- 从报表进入时，收支及现金流沿用分类、账户、资金来源和原单维度。净资产按所选币种
  及账户计算。周期、分类和账户明细均可打开对应流水。

## 原始账单

通用 CSV 的 `payment_channel`、`merchant` 或 `counterparty` 可用于筛选。微信支付
和支付宝适配器使用账单的支付方式和交易对方列。账单操作菜单内的「原始账单」保留
来源批次、文件名、行号及导入字段。人工匹配已有交易也会关联来源。撤销批次移除其
有效关联，并在导入历史保留批次记录。历史备份按原来保存的导入字段恢复。
