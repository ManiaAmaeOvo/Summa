# 产品基础设计

**简体中文** | [English](../product-foundation.md)

## 产品边界

Summa 是离线的单用户个人账本，优先支持 Android。数据保存在设备上，用户可按需导入、
导出和备份。实际交易、财务计划和预测分别记录或计算。

## 交易、账户与归属

- 交易表示一次经济活动。已入账记录通过逐币种平衡的分录改变账本，待入账记录需要确认。
- 账户采用稳定核算类型。包括现金、银行、钱包、储蓄、预付、受托资金、信用负债、应付他人和应收款。
  家庭直接承担使用独立的资金归属，不产生个人账户收付。
- 分类解决消费用途和收入来源，资金归属用于区分本人承担、家庭直接承担及受托支付。财务报表分别显示
  总消费、本人承担和个人现金流。
- 借入增加现金与负债，借出或垫付把个人资金转成应收本金。还款、收回本金和报销到账是本金流动，
  利息和手续费作为费用单列。混合 AA 支出可同时记录本人的消费与替他人垫付的应收。
- 转账保存两侧账户的实际金额。跨币种结算保留历史币种和报价。净资产估值独立使用当前估值设置。
- 报表按原交易、退款和冲销的余额及消费影响统计。校准和对账可记录明确的差额调整。

## 预算、授权额度与预测

支出预算按总消费、本人承担、类别、账户或资金来源等口径汇总。
外部授权额度按受托账户设置。周期重置模式在每期恢复到指定额度，以当期已入账刷卡分录计算
可用额，未使用额度到期。重置没有实际交易，因此不纳入净资产、个人现金流或收入。

订阅、周期收支、债务和应收合同可记录未来义务。现金流预测按币种结合计划、已入账记录和
账户余额。计划需要人工确认或关联实际交易。储蓄目标分配已有资金。

## 导入、导出与恢复

- 严格 JSON 导入支持结构化预览、编辑及原子提交。文件导入支持通用 CSV、微信和支付宝账单，
  并提供去重、匹配、分类规则试跑、人工复核和批次撤销。
- 财务报告按选定的币种、期间和筛选条件生成，可导出 JSON、CSV、XLSX 或 Markdown。
- 完整 JSON 备份保存稳定 ID、分录、导入来源、对账、估值和财务计划。支持事务性覆盖恢复和合并。

具体字段、流程和验收见 [用户手册](../../USER_GUIDE.zh-CN.md)、
[财务指标](../v2/FINANCIAL_METRICS.md) 与 [实施记录](../v2/PROGRESS.md)。
